Classify ground points with the Cloth Simulation Filter (PDAL's filters.csf): of the returns classified, ground points become class 2 and others class 1

Usage: terrio filter csf [OPTIONS] <INPUT> <OUTPUT>

Arguments:
  <INPUT>   The point cloud (LAS, LAZ, COPC, EPT, PLY or E57; a path, URL or `s3://` object)
  <OUTPUT>  The output: LAS, LAZ, COPC, PLY, E57 or EPT (`ept.json`), by its extension

Options:
      --cloth-resolution <CLOTH_RESOLUTION>
          The cloth's resolution (PDAL's resolution) [default: 1]
      --rigidness <RIGIDNESS>
          The cloth's rigidness (1 to 3) [default: 3]
      --step <STEP>
          The time step [default: 0.65]
      --threshold <THRESHOLD>
          The largest distance of ground points from the cloth [default: 0.5]
      --hdiff <HDIFF>
          The height difference threshold of slope handling [default: 0.3]
      --iterations <ITERATIONS>
          The most simulation steps [default: 500]
      --no-smooth
          No slope handling after the simulation
      --ignore <RANGES>
          Leave alone the points in these ranges (PDAL's ignore), such as "Classification[7:7]"
      --csf-returns <RETURNS>
          The returns classified (comma-separated): first, last, intermediate, only [default: last,only]
      --ground-class <GROUND_CLASS>
          The class of ground points [default: 2]
      --other-class <OTHER_CLASS>
          The class of other points [default: 1]
      --only-ground
          Change the class of ground points only
  -h, --help
          Print help

Point cloud options:
      --bounds <XMIN> <YMIN> <XMAX> <YMAX>
          Keep the points in these bounds, in the input's CRS
      --z-range <MIN> <MAX>
          Keep the points with z in this range
      --class <CLASSES>
          Keep the points of these classifications (comma-separated, such as 2,6)
      --returns <RETURNS>
          Keep these returns of each pulse (comma-separated): first, last, intermediate, only
      --max-level <LEVEL>
          COPC and EPT: read down to this octree level (0 is the root)
      --resolution <SPACING>
          COPC and EPT: read the octree levels needed for this point spacing
      --max-points <N>
          Read at most about this many points: COPC and EPT down to the deepest level that fits, others by keeping every n-th point
      --point-format <N>
          The output point data record format (0 to 10). By default, the input's (6 to 8 for COPC)
      --las-version <1.N>
          The output LAS version, such as 1.2 or 1.4. By default, the input's, raised as the point format needs
      --scale <X> <Y> <Z>
          The scale of the stored X, Y and Z
      --offset <X> <Y> <Z>
          The offset of the stored X, Y and Z
      --dims <DIMS>
          For vector, PLY and E57 outputs, the dimensions written (comma-separated). All by default
      --ply-encoding <ENCODING>
          PLY outputs: ascii (the default, as PDAL's), binary_little_endian or binary_big_endian
      --ply-precision <DIGITS>
          PLY ASCII outputs: the digits after the decimal point of floats (by default, as many as needed to read the same values back)
      --ept-data-type <TYPE>
          EPT outputs: how the nodes' points are stored: laszip (the default, as Entwine), binary or zstandard
      --chunk-points <N>
          The points read and written at a time: point clouds are converted in chunks, in bounded memory, whatever their size (about a million points by default) [default: 0]
