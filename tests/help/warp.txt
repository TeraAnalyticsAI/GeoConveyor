Reproject and resample rasters (like gdalwarp)

Usage: terrio warp [OPTIONS] <PATHS> <PATHS>...

Arguments:
  <PATHS> <PATHS>...  The input rasters, then the output path

Options:
      --s-srs <CRS>                     The sources' CRS, overriding what they declare
      --t-srs <CRS>                     The output CRS: `EPSG:4326`, WKT, a PROJ string, or a file holding one. By default, the first input's
      --tr <XRES> <YRES>                The output resolution, in output CRS units
      --te <XMIN> <YMIN> <XMAX> <YMAX>  The output extent, in output CRS units (or `--te-srs`)
      --te-srs <CRS>                    The CRS of `--te`
      --ts <WIDTH> <HEIGHT>             The output size in pixels; 0 computes one dimension from the other
      --tap                             Align the output extent on multiples of `--tr`
  -r, --resampling <RESAMPLING>         Resampling: near, bilinear, cubic, cubicspline, lanczos, average, rms, mode, min, max, med, q1, q3, sum [default: near]
      --srcnodata <SRCNODATA>           Source nodata values (one, or one per band), or `none` to ignore the sources'
      --dstnodata <DSTNODATA>           Output nodata values, or `none`. By default, the source nodata
      --ot <OT>                         The output data type (Byte, Int16, UInt16, Int32, UInt32, Float32, Float64...)
      --cutline <CUTLINE>               A vector file whose polygons mask the sources
      --crop-to-cutline                 Set the output extent to the cutline's
      --et <ET>                         Maximum error of the approximate transformer, in pixels (0: exact) [default: 0.125]
      --order <ORDER>                   The order of the polynomial fitted to the first source's GCPs (1, 2 or 3), as `gdalwarp -order`. By default, GDAL's choice
      --tps                             Fit thin plate splines to the first source's GCPs, as `gdalwarp -tps`
  -f, --format <FORMAT>                 The output format's short name (`GTiff`, `COG`...). By default, chosen from the output's extension [alias: --of]
      --compress <COMPRESS>             GeoTIFF/COG compression: NONE, LZW, DEFLATE, PACKBITS, JPEG, WEBP. GeoPackage tiles: PNG, JPEG
      --tile-size <TILE_SIZE>           GeoTIFF/COG tile size
      --bigtiff                         Write BigTIFF
      --co <KEY=VALUE>                  A creation option, as GDAL names it: `KEY=VALUE` (Zarr: FORMAT=ZARR_V2|ZARR_V3; netCDF: FORMAT=NC|NC2|NC5|NC4|NC4C, COMPRESS=DEFLATE, ZLEVEL=1..9, CHUNKING=YES|NO)
  -h, --help                            Print help
