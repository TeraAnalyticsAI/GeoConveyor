Terrain analysis: hillshade, slope, aspect, color relief, TRI, TPI, roughness (like gdaldem)

Usage: terrio dem [OPTIONS] <MODE> <INPUT> <OUTPUT>...

Arguments:
  <MODE>               The processing: hillshade, slope, aspect, color-relief, TRI, TPI or roughness
  <INPUT> <OUTPUT>...  The input DEM, then (for color-relief) the color file, then the output path

Options:
  -b, --band <BAND>            The band to process, from 1 [default: 1]
      --compute-edges          Compute values at the edges of the raster and next to nodata too
      --alg <ALG>              The algorithm: Horn or ZevenbergenThorne (hillshade, slope, aspect), Riley or Wilson (TRI)
  -z, --z-factor <Z>           Vertical exaggeration (hillshade) [default: 1]
  -s, --scale <SCALE>          Ratio of vertical to horizontal units (hillshade, slope); 111120 for a geographic DEM in metres. By default derived from the CRS
      --xscale <XSCALE>        Ratio of vertical to horizontal units along x (with --yscale)
      --yscale <YSCALE>        Ratio of vertical to horizontal units along y (with --xscale)
      --az <AZIMUTH>           Azimuth of the light, in degrees (hillshade)
      --alt <ALTITUDE>         Altitude of the light, in degrees (hillshade)
      --combined               Combined shading: hillshade and slope (hillshade)
      --multidirectional       Multidirectional shading (hillshade)
      --igor                   Igor's shading, which only darkens slopes facing away from the light (hillshade)
  -p, --percent                Slope as a percentage rather than in degrees (slope)
      --trigonometric          Aspect as a trigonometric angle rather than an azimuth (aspect)
      --zero-for-flat          Aspect of 0 rather than nodata for flat areas (aspect)
      --alpha                  Add an alpha band (color-relief)
      --exact-color-entry      Only color values that have an entry in the color file (color-relief)
      --nearest-color-entry    Use the color of the nearest entry rather than interpolating (color-relief)
  -f, --format <FORMAT>        The output format's short name (`GTiff`, `COG`...). By default, chosen from the output's extension [alias: --of]
      --compress <COMPRESS>    GeoTIFF/COG compression: NONE, LZW, DEFLATE, PACKBITS, JPEG, WEBP. GeoPackage tiles: PNG, JPEG
      --tile-size <TILE_SIZE>  GeoTIFF/COG tile size
      --bigtiff                Write BigTIFF
      --co <KEY=VALUE>         A creation option, as GDAL names it: `KEY=VALUE` (Zarr: FORMAT=ZARR_V2|ZARR_V3; netCDF: FORMAT=NC|NC2|NC5|NC4|NC4C, COMPRESS=DEFLATE, ZLEVEL=1..9, CHUNKING=YES|NO)
  -h, --help                   Print help
