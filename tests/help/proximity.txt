Distance from every pixel to the nearest target pixel (like gdal_proximity.py)

Usage: terrio proximity [OPTIONS] <INPUT> <OUTPUT>

Arguments:
  <INPUT>   The input raster
  <OUTPUT>  The output path

Options:
  -b, --srcband <BAND>                 The band of the input, from 1 [default: 1]
      --values <VALUES>                The target pixel values, comma-separated. By default, every non-zero pixel
      --distunits <DISTUNITS>          The distance units: PIXEL (the default) or GEO (georeferenced units) [default: PIXEL]
      --maxdist <MAXDIST>              The largest distance computed; farther pixels get the --nodata value
      --nodata <NODATA>                The value of pixels farther than --maxdist or without any target (65535 by default)
      --use-input-nodata               Keep the input's nodata pixels as --nodata in the output
      --fixed-buf-val <FIXED_BUF_VAL>  Give pixels within --maxdist this value instead of their distance
      --ot <OT>                        The output type (Float32 by default) [default: Float32]
  -f, --format <FORMAT>                The output format's short name (`GTiff`, `COG`...). By default, chosen from the output's extension [alias: --of]
      --compress <COMPRESS>            GeoTIFF/COG compression: NONE, LZW, DEFLATE, PACKBITS, JPEG, WEBP. GeoPackage tiles: PNG, JPEG
      --tile-size <TILE_SIZE>          GeoTIFF/COG tile size
      --bigtiff                        Write BigTIFF
      --co <KEY=VALUE>                 A creation option, as GDAL names it: `KEY=VALUE` (Zarr: FORMAT=ZARR_V2|ZARR_V3; netCDF: FORMAT=NC|NC2|NC5|NC4|NC4C, COMPRESS=DEFLATE, ZLEVEL=1..9, CHUNKING=YES|NO)
  -h, --help                           Print help
