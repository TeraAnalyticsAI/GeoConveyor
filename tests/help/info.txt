Summarize a raster, vector dataset or point cloud

Usage: terrio info [OPTIONS] <INPUT>

Arguments:
  <INPUT>  The dataset: a path, URL, `s3://` or `gs://` object, or zip archive

Options:
      --json             Print JSON
      --stats            Compute band statistics; for point clouds, read every point to count classifications and returns and give each dimension's range
      --hist             Compute band histograms as `gdalinfo -hist` does: 256 buckets over the type's range for Byte and Int8 bands, otherwise over the band's approximate minimum and maximum (exact with `--stats`) widened by half a bucket
  -l, --layer <LAYERS>   Only these layers of a vector dataset
      --driver <DRIVER>  Open the input with this driver: `gdal` uses the GDAL backend (builds with the `gdal` feature), as a `GDAL:` prefix on the path does
  -h, --help             Print help
