Turn a raster band into polygons of connected pixels with the same value

Usage: terrio polygonize [OPTIONS] <INPUT> <OUTPUT>

Arguments:
  <INPUT>   The raster
  <OUTPUT>  The output vector dataset

Options:
  -b, --band <BAND>      The band to polygonize (1-based) [default: 1]
      --field <NAME>     The name of the field receiving the pixel values [default: DN] [alias: --fieldname]
      --nln <NAME>       The output layer name. By default, the output file's name
      --8                Connect pixels through their corners too (8-connectedness). The default is 4
      --nomask           Do not leave out nodata pixels
      --mask <RASTER>    Leave out the pixels where the first band of this raster is 0
  -f, --format <FORMAT>  The output format's short name. By default, chosen from the output's extension
      --append           Add the polygons to the layer of the same name in an existing output
      --overwrite        Replace the layer of the same name in an existing output (other GeoPackage layers stay)
  -h, --help             Print help
