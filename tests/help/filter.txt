Filter a point cloud as PDAL's filters do: ground classification (SMRF, PMF, CSF), noise, heights above ground, crops, expressions, assignments, tiles, normals, clusters, sampling

Usage: terrio filter <COMMAND>

Commands:
  smrf                        Classify ground points with the Simple Morphological Filter (PDAL's filters.smrf): of the returns classified, ground points become class 2 and others class 1
  outlier                     Classify outliers as noise (PDAL's filters.outlier): statistical (mean distance to the nearest neighbours) or radius (too few neighbours within a radius)
  range                       Keep the points within ranges of dimensions (PDAL's filters.range), read and written in chunks
  sample                      Poisson sampling (PDAL's filters.sample): keep the points at least a radius from those kept before them
  voxeldownsize               Keep the first point of each voxel (PDAL's filters.voxeldownsize)
  voxelcenternearestneighbor  Keep the point nearest the center of each voxel (PDAL's filters.voxelcenternearestneighbor)
  pmf                         Classify ground points with the Progressive Morphological Filter (PDAL's filters.pmf): of the returns classified, ground points become class 2 and others class 1
  csf                         Classify ground points with the Cloth Simulation Filter (PDAL's filters.csf): of the returns classified, ground points become class 2 and others class 1
  elm                         Classify low noise with the Extended Local Minimum (PDAL's filters.elm)
  hag_nn                      Compute heights above the nearest ground points, in HeightAboveGround (PDAL's filters.hag_nn)
  hag_delaunay                Compute heights above a Delaunay triangulation of the nearest ground points, in HeightAboveGround (PDAL's filters.hag_delaunay)
  crop                        Keep the points in boxes, polygons, circles or spheres (PDAL's filters.crop)
  decimation                  Keep every n-th point (PDAL's filters.decimation)
  expression                  Keep the points for which an expression is true (PDAL's filters.expression), read and written in chunks, such as "Classification == 2 && Z > 100"
  assign                      Assign values to dimensions (PDAL's filters.assign)
  merge                       Merge point clouds into one (PDAL's filters.merge)
  splitter                    Split points into squares (PDAL's filters.splitter): a file per square when the output's file name has a '#' (replaced by 1, 2...), else all in one file, square after square
  chipper                     Split points into squarish chips of at most a number of points (PDAL's filters.chipper): a file per chip when the output's file name has a '#', else all in one file
  normal                      Compute normals and curvature (PDAL's filters.normal): NormalX, NormalY, NormalZ and Curvature
  cluster                     Label Euclidean clusters (PDAL's filters.cluster), in ClusterID
  help                        Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
