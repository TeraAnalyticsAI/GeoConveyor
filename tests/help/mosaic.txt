Mosaic rasters into one, or into a virtual raster (like gdalbuildvrt and gdal_merge)

Usage: terrio mosaic [OPTIONS] <PATHS> <PATHS>...

Arguments:
  <PATHS> <PATHS>...  The input rasters, then the output path. A `.vrt` output is a virtual mosaic referencing the inputs, as `gdalbuildvrt` writes

Options:
      --resolution <RESOLUTION>         The resolution: highest, lowest, average, or user (with `--tr`) [default: average]
      --tr <XRES> <YRES>                The output resolution (implies `--resolution user`)
      --te <XMIN> <YMIN> <XMAX> <YMAX>  The output extent
      --tap                             Align the extent on multiples of the resolution
      --separate                        Put each input in its own band instead of mosaicking them
  -b, --band <BANDS>                    A band to use, from 1; repeat for several
      --nodata <NODATA>                 Ignore input pixels with this value and use it as the output nodata
      --srcnodata <SRCNODATA>           Ignore input pixels with these values (or `none` to ignore the inputs' nodata)
      --dstnodata <DSTNODATA>           The output nodata (or `none`). By default, the inputs'
  -r, --resampling <RESAMPLING>         Resampling when inputs are resampled or reprojected [default: near]
      --t-srs <CRS>                     The output CRS; inputs in other CRSs are reprojected. By default, the first input's
  -f, --format <FORMAT>                 The output format's short name (`GTiff`, `COG`...). By default, chosen from the output's extension [alias: --of]
      --compress <COMPRESS>             GeoTIFF/COG compression: NONE, LZW, DEFLATE, PACKBITS, JPEG, WEBP. GeoPackage tiles: PNG, JPEG
      --tile-size <TILE_SIZE>           GeoTIFF/COG tile size
      --bigtiff                         Write BigTIFF
      --co <KEY=VALUE>                  A creation option, as GDAL names it: `KEY=VALUE` (Zarr: FORMAT=ZARR_V2|ZARR_V3; netCDF: FORMAT=NC|NC2|NC5|NC4|NC4C, COMPRESS=DEFLATE, ZLEVEL=1..9, CHUNKING=YES|NO)
  -h, --help                            Print help
